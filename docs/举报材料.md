## 五、关于"举报能不能给钱"——如实说明

1. **举报木马/黑客本身，国内基本没有现金奖励。** 没有"举报病毒领赏金"的常规制度。
2. **可能有钱的极少数情形**：
   - 刑事案件**立案后**，你作为受害方配合侦查、提供关键线索，办案单位可依当地奖励办法给予奖励（金额视案情，需立案，且不是"举报即付"）；
   - 企业 SRC / 威胁情报平台的积分、礼品、代金券（价值通常几十到几百元，非现金）；
   - 部分云厂商对"安全事件报告"给代金券补偿。
   - 注意：CNVD/CNNVD 是**漏洞**奖励，恶意样本不适用。
3. **不要相信"帮你追回损失/举报返利/黑客赔付"的中间人**。要求你先付费、加私人微信、远程操控你电脑、承诺"追回资金"的，99% 是二次诈骗。真要走钱的路，只有"报警立案"这一条。
4. **举报真正的价值不在钱**：
   - 让 C2 被下架/封禁，切断再次感染的通道；
   - 拿到报案回执，可用于保险理赔、客户说明、内部合规审计；
   - 留存证据链，避免后续被追责时说不清。

## 六、提交前必做的三件事

1. **保全证据**：把样本、`/etc/ld.so.preload`、`/etc/nsswitch.conf`、`/etc/.pm`、`/root/.ssh/authorized_keys`、`/etc/pam.d/common-auth`、`/etc/cron.d/*`、`systemctl list-units` 输出、`ps auxf`、`ss -antp` 全部打包留存（注意：此时看到的 `ps/ss` 结果可能已被过滤，需在**重装前**用外部只读方式取证）；
2. **先止损再举报**：清理/重建优先，举报流程往往以周计；
3. **不要在举报材料里写业务敏感信息**（数据库口令、客户数据、内网拓扑），只写主机 IP、时间、行为、哈希。
